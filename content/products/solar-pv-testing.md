# Solar PV Testing Equipment

## Instruments for Solar Photovoltaic System Commissioning and Maintenance

India's rapidly expanding solar PV sector demands rigorous testing at every stage — from module-level factory inspection through to string and plant-level commissioning and ongoing performance monitoring. Green Watt supplies a comprehensive range of solar PV test instruments, enabling EPC contractors, O&M providers, and utilities to verify PV system performance, detect faults, and maintain compliance with IEC 62446 and other applicable standards.

## Models Available

### MCM1600PV — Multi-function Solar PV Analyser
A flagship multi-function tester combining I-V curve tracing, insulation resistance, earth continuity, irradiance, and temperature measurement in a single portable instrument — ideal for rapid, comprehensive PV string and array commissioning.

**Key Features:**
- I-V and P-V curve tracing up to 1500 V / 30 A
- Spectral irradiance correction using reference cell or pyranometer input
- STC normalisation of measured I-V curve for comparison with datasheet
- Insulation resistance test up to 1000 V DC (bipolar method)
- Module temperature input for performance ratio calculation
- Bluetooth data transfer and dedicated smartphone/tablet app
- Compliant with IEC 62446-1

### MIS-PV / MIS-PVS — PV Insulation and String Tester
Portable insulation resistance testers specifically designed for the floating DC architecture of solar PV strings. The MIS-PVS adds string performance measurement capability.

**Key Features:**
- Bipolar insulation resistance measurement without disconnecting the array
- Test voltages: 250 V to 1500 V DC
- Minimum insulation resistance alarm (per IEC 62446)
- Open-circuit voltage and short-circuit current measurement (MIS-PVS)

### NSEI-100D — Solar Irradiance and Energy Logger
A precision solar irradiance measurement and data logging instrument for PV plant performance monitoring and yield assessment.

**Key Features:**
- Silicon reference cell and pyranometer sensor inputs
- Simultaneous multi-channel irradiance and temperature logging
- On-board data logger with configurable sampling interval
- Performance ratio and specific yield calculation

### MDLA-100A-DC — DC Current Data Logger / Analyser
A DC string current logger for continuous monitoring of individual string currents in a solar PV array — enabling rapid detection of underperforming or shaded strings.

**Key Features:**
- Up to 16 DC current channels simultaneously
- Clamp-on DC current sensors — no wiring modifications
- Web-based data access and alarm notification

## Applications

- PV system commissioning per IEC 62446-1 and IEC 62446-3
- String-level fault finding: shading, bypass diode failures, soiling, degradation
- O&M performance monitoring and yield optimisation
- Insurance and bankability assessment for solar assets
